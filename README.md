# Academic Success Classifier

A machine learning project designed to predict student academic outcomes (Graduate, Enrolled, Dropout) using structured educational data.

## Business Problem

Educational institutions face high student dropout rates, which impact funding, reputation, and student success.

This project builds a predictive system to:
- Identify at-risk students early
- Enable targeted academic interventions
- Improve graduation outcomes

## Solution

A Gradient Boosting model was trained on student academic and demographic data to classify outcomes with ~75% accuracy.

The system also includes a rule-based recommendation engine to provide actionable insights for student improvement.
